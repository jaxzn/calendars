How to subscribe

Apple Calendar (iPhone, iPad, Mac)

Tap Subscribe, then confirm. On a Mac you can also use File → New Calendar Subscription… and paste the link from Copy link. Set auto-refresh to every hour or day, and choose iCloud if you want it on all your devices.

Google Calendar

Click Google Calendar (on a computer), or in Google Calendar on the web go to Other calendars → + → From URL and paste the link from Copy link. It then shows up on your phone too. Google refreshes subscribed calendars on its own schedule, often every 8–24 hours.

Outlook

Outlook.com / Microsoft 365: Calendar → Add calendar → Subscribe from web, paste the link from Copy link. Classic Outlook for Windows: Add Calendar → From Internet.

Subscribe instead of importing a one-time download, or the calendar will not update. First pitches are stored in UTC so your calendar shows them in your own time zone. Games whose date or time is not set yet appear as all-day placeholders until MLB schedules them. Each game of a doubleheader is its own event. A postponed game stays cancelled under its original listing; the makeup is a separate game once ESPN posts it. A suspended game keeps its original listing and moves if the resume date changes.
